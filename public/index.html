关于

          
本地知识图谱整合器 —— 把文档与联网信息整理成可导航的 3D 知识图谱。全流程本地运行，数据存于本机 data/ 目录（独立 Git 仓库托管，可回溯）。

          
版本与更新

          

          
详细帮助文档：浏览器在线查看 HELP.md（项目目录下）

          
程序化接入 SDK：SDK.md（零依赖客户端 /sdk/kg-client.mjs，不经 MCP）

          
命令行工具：CLI.md（kgctl，无需服务运行即可读写图谱）

          
发布记录：GitHub Releases

          
快速上手

          
    
            
  • AI 对话建图：右侧输入自然语言（如"联网查一下珠穆朗玛峰的海拔并建入图谱"），或上传文档（md/txt/pdf/docx）批量抽取
    • 
            
  • 检索页签：智能提问（一句话找关系）、语义/关键词混合检索；语义配置卡可填 Base URL/Key/模型并一键测试连接
    • 
            
  • 关系推荐：共同邻居找"该连没连"的实体对（检索页签"关系推荐"卡 / 实体卡"推荐关系"按钮），AI 判断后一键采纳入库
    • 
            
  • 最短路径：搜索或列表选中实体后，用"路径"功能查两实体关联链路
    • 
            
  • 撤销：按钮或 Ctrl+Z，可连续撤销；删除实体仅恢复实体本身，关联关系可在日志页看到级联记录
    • 
            
  • 推理：开关叠加虚线显示的隐性关系（传递/对称/逆规则），点击可见推导依据
    • 
            
  • 保存点与回溯：版本页签打保存点，随时回滚到任一历史状态
    • 
            
  • 图片绑定：实体与关系信息卡上传本地图片（缩略图+灯箱），佐证材料随图谱留存
    • 
            
  • 导出：RDF(Turtle)、整库 .db、单文件只读网页版
    •

数据安全

          
图谱数据、图片、API Key 全部保存在本机数据目录（npm 安装在 ~/.local-knowledge-graph/，Git 克隆在项目内 data/）。语义检索的 API Key 仅存本地，服务端永不回传真实值。

系统
输入自然语言指令（如"帮我联网查一下珠穆朗玛峰的海拔并建入图谱"）。OpenCode 将校验信息后提交操作，所有写入均需通过RDF规范校验。

      

      

        

          
          
        

        
        

          
          
        

        
        
OpenCode 进程由后端默认拉起；仅它可联网补全公开信息，本地图谱数据不对外传输。文档经 kg-triples 技能抽取并校验后融合入库。
